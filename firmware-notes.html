MQTT Observer v1.18.0
  • Based on MeshCore 1.18.0
  • Up to 6 MQTT broker slots with built-in community presets
  • Presets include Analyzer, MeshMapper, MeshRank, Waev, Meshomatic, CascadiaMesh, TennMesh, NashMesh, IdahoMesh, and more
  • Per-slot region code override (mqttN.iata) for brokers with different region maps
  • JWT (Ed25519) and username/password authentication
  • Web config portal on the device, plus serial console (115200 baud)
  • Over-the-air updates; switch release channel with ota branch prod|beta, then ota update
  • Neighbor discovery uplink on supported boards
  • Self-heal (opt-in): if MQTT gets stuck in a state that used to need a manual reboot (a bridge stop that never completes, a client that cannot be reused, or every broker slot down for over two hours while the internet is reachable), the node sends an alert and reboots itself one minute later. When all slots are down it reboots once per outage, not repeatedly. Off by default; set mqtt.selfheal on enables it and get mqtt.selfheal shows the last cause.
  • Crash reports: after a panic the node reads back the saved core dump. get crash shows the task, PC and backtrace, the status message carries it once, and clear crash erases it.
  • New diagnostics: get mqtt.stacks (task stack headroom), plus heap_min and reset_reason in the status message. get mqtt.ntp.diag no longer blocks.
  • Lower memory use on ESP32-S3 boards without PSRAM (Heltec V3, WSL3, Wireless Paper, Wireless Tracker, RAK 3112): a smaller TLS send buffer frees about 12 KB per broker connection.
  • Faster, paced broker startup and reconfiguration, a fix for a rare crash in DNS lookups, and more stack headroom on the MQTT task.

See setup guide for configuration instructions.
